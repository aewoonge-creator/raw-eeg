# raw EEG

[웹 GUI 열기](https://aewoonge-creator.github.io/raw-eeg/)

EEG Plot Lab과 별개의 오프라인 CSV 파형 뷰어입니다. `index.html`을 브라우저에서 열면 됩니다.
서버, 설치, 인터넷 연결이 필요하지 않으며 CSV는 외부로 전송하지 않습니다.

## 기능

- Raw: 채널별로 선택한 원본 파형 최대 8줄.
- Bipolar: A와 B 전극을 선택해 같은 샘플의 A-B 파형, 최대 8쌍. 전극명 편집 가능.
- 기록 전체 미리보기 위의 선택 구간을 드래그해 이동하고 양쪽 끝을 드래그해 구간 길이를 조절합니다.
- 아래 시간 슬라이더(키보드 지원), 시작 시간, 구간 길이, 이전/다음 구간, 재생/정지.
- 표시 단위, 세로 배율, 표시 기준선 선택, 현재 파형 PNG 저장.
- 인터넷 없이 쓰도록 Papa Parse와 Lucide를 vendor에 포함했습니다.

## 원본 데이터 원칙

필터, 평활화, 자동 이상값 제외, 보간은 적용하지 않습니다. 채널 중앙 기준선은 표시 좌표의
중심만 바꾸며 실제 값은 커서에서 볼 수 있습니다. 원본 배열은 변경하지 않습니다.
확대/축소 시 픽셀별 최소/최대값으로 표시해 좁은 spike를 유지합니다.
빈 값과 비수치 값은 0으로 바꾸지 않고 파형을 끊습니다. 긴 시간 간격도 연결하지 않습니다.

`t_us`, `t_ms`, `time` 등의 실제 시간 열을 우선 사용하며 첫 시각을 0초로 표시합니다.
시간 열이 없으면 sample 번호 또는 행 순서와 샘플링 주파수를 사용합니다. 주파수 정보도
없으면 250 Hz 임시값과 경고를 표시하므로 CSV / 시간 설정에서 실제 Hz를 입력하세요.
시간이 중복되거나 역전되면 표시를 중단하고 시간 설정 수정을 요구합니다.

단위를 확인할 수 없는 CSV는 원본 단위로 표시합니다. ADC counts를 µV로 바꾸려면 CSV에
VREF 및 채널별 Gain 정보가 있어야 합니다. 서로 다른 Gain의 counts는 직접 차감하지
않고 µV로 환산한 다음 bipolar를 계산합니다. 두 입력은 같은 시점, 같은 물리 단위이며
서로 호환되는 기준 전극으로 측정됐어야 합니다. 이미 서로 다른 차동 입력으로 측정한
채널의 차는 새로운 전극 한 쌍의 전압과 같지 않을 수 있습니다.

데모는 90초 합성 신호이며 실제 EEG가 아닙니다. 본 도구는 연구용 원본 확인 도구이며
임상 진단을 제공하지 않습니다. 필터 기능은 이 버전에 포함하지 않았습니다.

## 검증

```powershell
node --test tests/core.test.cjs
node tests/browser.cjs
```

브라우저 테스트는 `playwright` 설치와 Edge가 필요합니다. `PLAYWRIGHT_MODULE` 환경변수로
설치된 Playwright 모듈 경로를 지정할 수 있습니다. 애플리케이션 자체에는 의존성 설치가 필요 없습니다.

## 라이브러리

- [Papa Parse 5.5.3](https://www.papaparse.com/docs), MIT. CSV 인용/구분자 처리.
- [Lucide 0.468.0](https://lucide.dev/guide/), ISC. 아이콘.
- 라이선스는 `vendor/`에 포함됩니다.
