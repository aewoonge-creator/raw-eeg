# raw EEG

[웹 GUI 열기](https://aewoonge-creator.github.io/raw-eeg/)

EEG Plot Lab과 별개의 오프라인 CSV 파형 뷰어입니다. `index.html`을 브라우저에서 열면 됩니다.
서버, 설치, 인터넷 연결이 필요하지 않으며 CSV는 외부로 전송하지 않습니다.

## 기능

- Raw: 채널별로 선택한 원본 파형 최대 8줄.
- Bipolar: A와 B 전극을 선택해 같은 샘플의 A-B 파형, 최대 8쌍. 전극명 편집 가능.
- 채널/Bipolar 구성과 별개의 Raw / Filtered 탭. 원본과 필터 결과를 같은 시간 구간에서 전환합니다.
- HPF, LPF 개별 ON/OFF 및 차단 주파수 입력. Notch 50 Hz, 60 Hz, 동시 적용 및 Q 조절.
- HPF / LPF / 전원 잡음 제거의 적용 순서 6가지, Notch 또는 Multitaper 회귀 선택, 고조파 옵션.
- 비교 탭: 선택 채널 또는 bipolar 한 쌍의 Raw / Notch / Multitaper를 동일 구간과 공통 세로 배율로 비교.
- 비교 탭 하단: 표시 구간의 전원 대역 Welch PSD (Raw / Notch / Multitaper).
- 기록 전체 미리보기 위의 선택 구간을 드래그해 이동하고 양쪽 끝을 드래그해 구간 길이를 조절합니다.
- 아래 시간 슬라이더(키보드 지원), 시작 시간, 구간 길이, 이전/다음 구간, 재생/정지.
- 표시 단위, 세로 배율, 표시 기준선 선택, 현재 파형 PNG 저장.
- 인터넷 없이 쓰도록 Papa Parse, Lucide, Fili를 vendor에 포함했습니다.

## 원본 데이터 원칙

Raw 보기에는 필터, 평활화, 자동 이상값 제외, 보간을 적용하지 않습니다. 채널 중앙 기준선은 표시 좌표의
중심만 바꾸며 실제 값은 커서에서 볼 수 있습니다. 원본 배열은 변경하지 않습니다.
확대/축소 시 픽셀별 최소/최대값으로 표시해 좁은 spike를 유지합니다.
빈 값과 비수치 값은 0으로 바꾸지 않고 파형을 끊습니다. 긴 시간 간격도 연결하지 않습니다.

`t_us`, `t_ms`, `time` 등의 실제 시간 열을 우선 사용하며 첫 시각을 0초로 표시합니다.
시간 열이 없으면 sample 번호 또는 행 순서와 샘플링 주파수를 사용합니다. 주파수 정보도
없으면 250 Hz 임시값과 경고를 표시하므로 CSV / 시간 설정에서 실제 Hz를 입력하세요.
시간이 중복되거나 역전되면 표시를 중단하고 시간 설정 수정을 요구합니다.

단위를 확인할 수 없는 CSV는 원본 단위로 표시합니다. ADC counts를 µV로 바꾸려면 CSV에
VREF 및 채널별 Gain 정보가 있어야 합니다. 서로 다른 Gain의 counts는 직접 차감하지
않고 µV로 환산한 다음 bipolar를 계산합니다. 두 입력은 같은 시점, 같은 물리 단위이며
서로 호환되는 기준 전극으로 측정됐어야 합니다. 이미 서로 다른 차동 입력으로 측정한
채널의 차는 새로운 전극 한 쌍의 전압과 같지 않을 수 있습니다.

데모는 90초 합성 신호이며 실제 EEG가 아닙니다. 본 도구는 연구용 원본 확인 도구이며
임상 진단을 제공하지 않습니다.

## 필터

CSV를 열면 항상 Raw 보기로 시작합니다. 필터 설정을 바꿔도 Raw는 그대로입니다.
Filtered 탭에서만 필터 결과를 표시하며, Bipolar에서도 원본 A-B와 필터 적용 A-B를 구분합니다.
기본 설정은 HPF 0.5 Hz, LPF 45 Hz, Notch 60 Hz / Q 30이며 각각 끌 수 있습니다.
모두 끄면 Filtered도 원본과 같은 값을 별도의 배열로 표시합니다. PNG 파일명과 헤더에
Raw/Filtered 및 적용 설정을 기록합니다.

Fili 2.0.3의 2차 biquad를 사용합니다. 기본 순서는 HPF → LPF → 전원 잡음이며,
`적용 순서`에서 6가지 순열 중 하나를 선택할 수 있습니다. OFF 단계는 건너뜁니다. HPF/LPF는
Butterworth(Q=1/√2), Notch는 선택 중심 주파수의 bandstop입니다. 각 단계는 2차이며,
여러 단계의 전체 필터 차수는 합산됩니다. **단방향 IIR이므로 위상 지연이 있으며,
zero-phase 필터가 아닙니다.** 시작 및 끊긴 구간 주변에는 과도응답이 있을 수 있습니다.

표시 구간이 아니라 전체 기록에 먼저 적용합니다. 타임라인을 이동해도 다시 시작하지 않습니다.
빈 값은 NaN으로 남기고, 빈 값/표본 간격이 1.5배를 넘는 지점에서 상태를 초기화합니다.
각 연속 구간의 첫 값을 일정한 이전 입력으로 가정해 큰 DC 시작 스파이크를 줄입니다.
자동 보간이나 데이터 채우기는 하지 않습니다.

필터 Fs는 CSV에 선언된 샘플링 주파수 또는 사용자가 적용한 Hz를 우선하며,
없으면 실제 시간축의 중앙 표본 간격에서 추정합니다. 화면의 Fs를 확인하세요.
차단 주파수는 0~Nyquist(Fs/2) 사이여야 하고 HPF < LPF여야 합니다.
큰 시간 불규칙성이나 설정 주파수 불일치는 필터 표시를 차단합니다. Raw는 계속 볼 수 있습니다.
자동 배율은 각 보기의 값에 맞춰 바뀌므로 동일 배율 비교에는 고정 /div 값을 선택하세요.
비교 탭의 자동 배율은 세 방법에 공통입니다. 채널 중앙 표시 기준선은 각 결과의 중심을
사용하므로 DC 변화는 옆의 `기준` 값으로 확인하거나 표시 기준선을 0으로 선택하세요.

### 필터 순서의 해석

고정 계수의 선형 시불변 필터끼리는 이상적으로 순서를 바꿔도 같은 결과입니다. 실제 차이는
초기 상태, 구간 경계, 수치 오차 등에서 생길 수 있습니다. 여기서는 double precision과
일정한 이전 입력을 가정한 초기화를 사용합니다. 순서를 바꿀 때 인위적인 차이를 만들지 않습니다.
Multitaper는 데이터에서 주파수와 유의성을 추정하는 적응형 처리이므로, HPF/LPF를 앞에
적용했는지에 따라 검출과 결과가 달라질 수 있습니다. 특정 순서가 모든 EEG에 최선인 것은 아닙니다.

### Multitaper 회귀 (PREP 참고)

**원본 EEGLAB CleanLine 또는 PREP 전체의 포팅/재현이 아닌, 논문의 원리를 참고한 별도 구현입니다.**
이상 채널 보간, robust reference, ICA는 수행하지 않습니다. Notch와 달리 유의하게 검출된
정현파를 추정해 빼며, 전원 전압 자체나 하드웨어 결함을 고치는 기능이 아닙니다.

- SciPy 1.14.1 `signal.windows.dpss`로 생성한 7개 Slepian taper (NW=4, L2 정규화).
  수치 테이블은 `vendor/dpss.js`, 재생성 코드는 `scripts/generate-tapers.py`에 있습니다.
  실행 시 Python/서버는 필요하지 않습니다. 신호를 재표본화하거나 taper를 보간하지 않습니다.
- 준비된 창 길이 512, 1000, 1024, 2000, 2048, 4000, 4096, 8192 샘플 중 4초에 가장
  가까운 길이를 선택합니다. 250 Hz에서는 정확히 4초 / 2 Hz 대역폭입니다. 실제 창 길이와
  대역폭은 상태에 표시합니다. 2~8초 창을 지원할 수 없는 Fs는 오류로 차단합니다.
- 각 연속 구간을 75% 중첩 창으로 처리합니다. 추정용 사본에서만 직선 추세와 평균을 제거합니다.
  원래 값에서 빼는 것은 추정된 정현파뿐이며, HPF를 별도로 켜지 않으면 DC/선형 추세는 보존됩니다.
- Fili FFT로 각 taper의 스펙트럼을 구하고 지정 주파수 ±2 Hz에서 복소 진폭의
  Thomson F(2,12) 통계량이 최대인 주파수를 찾습니다. FFT bin 사이도 직접 Fourier 합으로
  정밀 탐색합니다. p=0.01에 검색 대역의 독립 주파수 개수에 대한 Bonferroni 보정을 적용합니다.
- 목표 주파수마다 창당 한 성분을 추정합니다. 재구성 잡음을 Hann 가중 중첩 평균한 후 뺍니다.
  전원 주파수는 50/60 Hz 또는 둘 다이며, 고조파를 켜면 Nyquist 미만의 정수배를 포함합니다.
  Notch 비교에도 같은 목표 주파수 집합이 적용됩니다.
- 원본 PREP의 임시 1 Hz 고역통과 사본, sigmoid 중첩, 최대 10회 반복과는 다릅니다.
  본 구현은 창별 직선 추세 제거, Hann 중첩, 목표별 1회 추정 및 보정된 검정 기준을 사용합니다.
  따라서 원본 PREP와 동일한 결과나 연구 검증 수준을 보장하지 않습니다.
- NaN/시간 단절을 넘어서 처리하지 않습니다. 창보다 짧은 연속 구간은 전원 잡음을 제거하지 않고
  미처리 샘플 수로 표시합니다. HPF/LPF를 켠 경우 그 단계는 해당 구간에도 적용됩니다.
  검출 건수는 전체 기록 기준이며, 여러 고조파가 있으면 창 수보다 클 수 있습니다.

빠르게 변하는 잡음, 넓게 퍼진 전원 간섭, 근전도, 움직임, 포화 등은 이 방법으로 해결되지
않을 수 있습니다. 지정 대역의 실제 신경성 정현파와 전원 잡음을 자동으로 구별할 수도 없습니다.
유의성 검정에는 오검출/미검출 가능성이 있습니다. 연구 결론은 원본 파형과 PSD를 함께 확인하세요.

### 비교 화면

비교를 열면 전원 잡음 단계는 ON으로 고정되고, Notch와 Multitaper가 같은 선택 채널/쌍,
같은 HPF/LPF, 같은 순서, 같은 시간축으로 각각 처리됩니다. Raw는 아무 필터도 적용하지 않습니다.
두 처리 방식만 비교할 때는 HPF/LPF를 끌 수 있습니다. 특히 LPF가 50/60 Hz보다 낮으면
전원 잡음이 이미 감쇠되므로 차이가 작게 보일 수 있으며 화면에 경고합니다.
Notch Q는 Notch에만 적용되며 Multitaper의 파라미터가 아닙니다.

PSD는 **현재 보이는 구간**에 Hann 창, 50% 중첩, 창별 평균 제거를 적용한 단측 Welch 밀도입니다.
최대 2초 이하의 2의 거듭제곱 창을 사용하며 실제 Δf와 유효 창 수를 표시합니다.
NaN/시간 단절이 있는 창은 제외합니다. 세 곡선의 축과 단위는 동일하며 y축은
10log10(PSD), 기준은 1 (표시 단위)²/Hz입니다. 짧은 표시 구간에서는 주파수 분해능이 낮아집니다.
PSD는 기본파 주변 ±5 Hz (50+60 선택 시 45~65 Hz)를 표시하며, 고조파 전체 스펙트럼은 아닙니다.
합성 데모에는 비교용 60.2 Hz 성분을 포함했습니다. 실제 측정 신호로 효과가 검증됐다는 뜻은 아닙니다.
